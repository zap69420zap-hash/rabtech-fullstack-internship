# Full Stack Web Development Internship — Tasks 02 & 03

A starter-ready, accessible dashboard foundation for the RabTech Academy internship tasks.

## Included
- Semantic HTML5 dashboard (`client/index.html`)
- Accessible component demo (`client/components.html`)
- Responsive CSS and lightweight JavaScript
- Architecture/audit documentation
- Test checklist and issue log template
- Server placeholder with a simple Node.js health endpoint
- No framework or paid dependencies required

## Run locally
1. Install Node.js (v18+ recommended).
2. In a terminal, enter `server/` and run `npm install` (there are no runtime dependencies).
3. Run `npm start`.
4. Open `http://localhost:3000`.

You can also open `client/index.html` directly, but the server route is useful for demonstrating the monorepo.

## Important honesty note for Task 02
`docs/accessibility-audit-report.md` contains the audit procedure and an issue log template. It does **not** claim that Lighthouse or a keyboard audit has been run against a third-party website. Run Lighthouse yourself on the chosen public website, add your real screenshots/results, and record the evidence before submitting. Do not submit placeholder evidence as if it were measured.

## Suggested evidence to capture
- Lighthouse report screenshot for the chosen public website
- Keyboard-only walkthrough (Tab, Shift+Tab, Enter, Space, Escape where relevant)
- GitHub repository page showing `docs/`, `client/`, `server/`, and `tests/`
- Screenshot of dashboard at desktop and mobile widths
